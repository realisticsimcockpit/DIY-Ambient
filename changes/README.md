# Différence depuis 0.1.0

Le patch couvre les sources, tests, scripts et documentation modifiés/ajoutés ; il exclut les sorties générées, journaux d’audit, ce dossier et le manifeste de distribution. Les fins de ligne et BOM peuvent être normalisés dans la représentation textuelle du patch. Utiliser les fichiers complets du ZIP pour construire la révision.

`files-changed.json` donne les empreintes binaires exactes avant/après. `SOURCE_MANIFEST.sha256` couvre tous les fichiers livrés sauf lui-même.
