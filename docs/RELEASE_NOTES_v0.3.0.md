# DIY Ambient light EVO v0.3.0

DIY Ambient light EVO by REALISTIC SIMCOCKPIT is a SimHub plugin for three screen cockpit lighting with 60 Adalight LED addresses.

This release includes idle and in game modes, automatic game profiles, screen capture, fixed colors, four animations, RPM lighting, and telemetry alerts. The pit alert flashes LEDs 1, 3, 5 through 59 in blue. It also includes the updated Arduino Nano firmware and a guided firmware update in the plugin.

## Install

1. Close SimHub.
2. Copy `DIYAmbient.Plugin.dll` beside `SimHubWPF.exe` in the SimHub installation folder.
3. Restart SimHub. Open **DIY Ambient light EVO** and configure the COM port and monitor mapping.

The tested firmware target is Arduino Nano ATmega328P with the standard bootloader. The firmware is uploaded only on request. Screen capture uses Windows GDI in SDR. The 15 A software current limit is an estimate, not a current measurement.
